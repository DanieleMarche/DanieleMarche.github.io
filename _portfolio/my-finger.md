MyFinger is my reimplementation of `finger`, the classic Linux command that shows information about the system's users. I built it for the **Operating Systems** course at Sapienza.

The program gets all its information directly from Linux system files, such as the user database and login records, without calling higher-level tools. It then formats the output the way the original command does.

<hr>

### Technologies used

- **Language:** C
- **Platform:** Linux system files and the standard C library
