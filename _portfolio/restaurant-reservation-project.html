The technologies used were Flutter and Firebase. The application actually sends the data of the reservation to a Firestore database. I left it unfinished when I moved on to another project, and because I had doubts about its commercial potential: it was meant to be sold to restaurants as a service.

This project was intended as a multiplatform application. That's why I chose Dart and Flutter, which build for several platforms from a single codebase. The UI uses the Material UI library. The date picker was written by Vivek Kaushik, and I adapted it for the app. Reservations are stored in Firestore, a non-relational database, in a single document. Right now reservations reach the database, but the UI and UX still need work.
